## 4. 账号、身份与旧 ID 映射

为杜绝旧 AGY 配置名与插件实例 ID 混淆、以及默认绑定切换导致在途会话串账号，本包建立了显式身份映射：

| 字段 | 语义与示例 | 持久化 / 运行时位置 |
| --- | --- | --- |
| `pluginId` | 插件包 ID（`core.harness.agy` / `hm.plugin.agy-driver-lite`） | `AgyProviderIdentity`、注册表 |
| `pluginInstanceId` | 插件实例 ID（`harness-agy` / `harness-agy-work` / `hm.plugin.agy-driver-lite`） | `native_runtime_provider_mappings.runtime_provider_instance_id`、`resource_owners` |
| `driverProviderInstanceId` | 驱动提供方插件实例 ID（绑定创建会话时的驱动归属） | `native_runtime_provider_mappings.driver_provider_instance_id`、`resource_owners` |
| `runId` | 插件进程 / 激活代次 ID | `native_runtime_provider_mappings.runtime_run_id` |
| `profileInstanceId` | 旧 AGY 账号 profile ID（保留 `agy`、`agy.work` 等旧值兼容） | `native_runtime_provider_mappings.profile_instance_id`、`agyProfiles` |
| `harnessId` | 会话逻辑引擎 ID（保留 `agy`、`agy.*` 默认别名；外部同类为 `<instanceId>:agy`） | `sessions.harness_id`、`native_runtime_provider_mappings.harness_id` |
| `nativeSessionId` | 底层 ACP / CLI 原生会话 ID（跨重启与旧会话恢复保持不变） | `sessions.native_session_id` |
| `runtimeId` / `generation` | 原生运行时绑定 ID 与单调代次令牌 | `native_runtime_bindings`；陈旧代次命令/控制/审批返回 `409 STALE_BINDING` |

- **在途固定**：`resolveAgyRuntimeProvider`（`packages/daemon/src/core/agy-peer-router.ts`）优先按会话已记录的所有者（`resource_owners`）与 `driverProviderInstanceId` 路由，在途句柄、快照、命令、控制与结算始终固定原实例与代次，即使全局默认绑定切换至另一账号实例也不会串单。

## 6. 路由、WS 与页面迁移

### 后端兼容转发与停用语义
- `packages/daemon/src/server/app.ts` 不再直接构造 `AgyAuthService`、`AgyNativeRuntimeRegistry`、`wireAgyNativeRuntime` 或 `AgyAdapter`。
- 旧路径 `/api/v1/harnesses/agy/*`、`/api/v1/sessions/:id/agy/*`、`/api/v1/sessions/:id/native/*` 与 Native WS 网关（`routes.ts` / `ws-feed.ts`）保留原 URL、DTO 与帧语义，全部通过 `agy-peer-router.ts` 转发至对应持有实例的 `agy.accounts.v1` / `agy.runtime.v1`。
- `NativeRuntimePort`（`packages/daemon/src/core/runtime-ports.ts` & `host-runtime-ports.ts`）收敛为可序列化 DTO/资源引用窄客户端（`bindingDto`、`bindingRef`、`decideTurnSettlementDto`），不再把内部类或厂商 `instanceof` 暴露给宿主。
- **零宿主 fallback 与停用隔离**：
  - 停用 `hm.plugin.agy-workbench-default` 仅卸载工作台服务与 UI 贡献，**不终止**后台 AGY 轮次。
  - 停用 `core.harness.agy` 实例后立即停止接单，所有旧 REST/WS 路由明确返回 `409 E_PLUGIN_DISABLED`（无宿主补建或回退），仅将该实例拥有的绑定标记为 `reconciling`，并清理该实例的连接、认证任务、观察器、outbox worker 与句柄；重新启用后可恢复。

### 前端工作台迁出
- 从 `packages/web/src/App.tsx`、`packages/web/src/slots/PluginSlotSync.tsx` 与 `packages/web/src/plugins/chat-default/main.tsx` 移除全部 7 项宿主 AGY 视图注册、`AgyNativeSidebarBadge`、`AgyNativeInspectorAdapter` 及 `core.harness.agy` 硬编码槽位注册。
- `packages/web/src/plugins/chat-default/ChatStage.tsx` 移除 `<AgyWorkbenchShell>` 直接导入，改为按 `agy.workbench.v1` 绑定通用挂载 `session.stage.embedded`（`BoundSessionSurface`）。
- 捆绑前端构建配置 `packages/web/vite.agy.config.ts` 内置 `agy-workbench-ownership-check` Rollup 守卫，构建阶段强制拒绝打包宿主 `stores/app-store.ts`。

## 7. W1→W2 临时旧审批窄适配与可运行交接示例

本包未重写 W2 统一审批服务。W1 明确持有 **native 协议报文、选项列表、bindingRevision/generation 校验与执行回执账本**；统一请求状态机、多端/策略决策与计时器留由 W2 接管。

- **契约与 DTO**：`packages/plugin-api/src/agy-contracts.ts` 中的 `AgyLegacyApprovalBridgeRequestDto`、`AgyLegacyApprovalBridgeResolveInputDto`、`AgyLegacyApprovalBridgeResolveResultDto`、`AgyLegacyApprovalBridgeInfoDto`（`mode: 'w1_temporary_narrow_adapter'`, `handoffTarget: 'runtime.requests.v1'`）。
- **可运行消费示例**：`packages/plugin-sdk/src/testing.ts` 中的 `createAgyLegacyApprovalBridgeSample`，已在 `packages/daemon/tests/b4-w1-contracts-fixtures.test.ts` 与 `packages/daemon/tests/b4-w1-agy-plugin-group.test.ts` 中运行验证，覆盖：
  1. 请求注册（携带 `approvalId`、`nativeRequestId`、`binding`、`bindingRevision`、原生 `options`、绝对 `deadlineAtMs`、`settlementRef`）
  2. 旧 `generation` 拒绝（`staleGeneration: true`）与 `expectedBindingRevision` CAS 冲突拒绝（`conflict: true`）
  3. 有效 CAS 回复单次投递与幂等重放（`accepted: true`, `receiptState: 'delivered'`）
  4. `acknowledgeSettlement(settlementRef)` 一次结算语义（首次 `acknowledged: true`，重复 `duplicate: true`）
  5. 超时截止自动进入 `expired` 终态。
