## 实现

- 外部终端订阅比较前后快照的内容。旧快照仍是新内容前缀时发送增量，缓冲滚动或缩短时发送替换快照。异步轮询逐次执行，取消订阅时取消待建立的订阅，提供实例撤销或切换代次后停止旧轮询。临时调用失败保留重试。
- `core.account-usage` 与 `core.mcp-hub` 各自发布 `workspace.pages` 页面及包内 HTML、JS 和 CSS。页面通过所属实例的路由读写用量、策略和 MCP 配置。后端路由随实例启停撤销，保留已有配置操作队列和服务生命周期。
- 用量页保留额度刷新、重置时间、Token 趋势、本机成本、缓存统计、手动 AGY 账号切换及策略编辑。MCP 页保留筛选、预设、确认安装、逐目标回执、失败目标重试、启停和确认移除。
- 宿主模态框按当前作用域解析实例并加载其页面。侧栏按契约提供方显示入口，支持预装实例停用后打开外部实现。模态框设置插件页面的可见高度，会话或工作区切换后重新挂载相应实例。
- 新增通用 UI 桥接 `session.switchHarness`，插件以 `{ targetHarnessId }` 请求切换当前会话，沿用已有会话切换动作。已卸载的页面不能发起切换。
- 原分叉合并测试改用账本插件的现有 `PUT /api/v1/sessions/:id/task-state` 接口。
- daemon 集成测试统一使用 60 秒预算，覆盖 Windows 下的插件进程、真实 Shell 和数据重启。4,200 事件的桌面历史导入测试沿用此预算，删除原先覆盖全局配置的 20 秒上限；断言与产品超时配置保持原样。

插件页面可通过 `window.harnessMate.call('session.switchHarness', { targetHarnessId })` 切换当前会话。不存在的目标返回 `E_INVALID_INPUT`，当前会话缺失或页面已卸载返回 `E_SERVICE_UNAVAILABLE`。
