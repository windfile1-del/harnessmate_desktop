# 开发提示词 · B1-02 本机历史来源

你是 HarnessMate Desktop 第一批解耦的历史来源开发人。请**实现 Codex、Claude、AGY 本机历史来源插件及一个可独立安装的自定义来源**，交付源码和可复跑证据。总指挥负责接口裁定、独立验收和合并结论。 [任务单](../../plugin-decoupling-batch-1-tasks.md)

## 开工

在 `D:\HarnessMate\harnessmate_desktop` 相关开发目录运行 `git status -sb` 和 `git rev-parse HEAD`，核对已分配的共同基线，保留用户和其他任务的改动。使用 B1-01 确认的 `history.source.v1`。契约未确认时可以先盘点真实存储、整理夹具、测试既有解析，再按确认后的接口接线。临时文件和测试数据放 D 盘。

复用 [历史扫描器](../../../packages/daemon/src/harnesses/history-scanner.ts) 和 [AGY 历史读取](../../../packages/daemon/src/harnesses/agy/native/recovery/history-source.ts)。现有扫描逻辑是事实基线。查明每个来源发现和读取正文分别走到哪里。

## 实现要求

1. 把 Codex、Claude、AGY 来源通过同一公开契约注册。`discover` 支持来源、筛选和分页，返回稳定来源身份、原生会话 ID、标题、时间和工作区线索。`read` 接收所选来源的会话引用，返回可续读的条目和读取状态。根目录由来源实例配置和解析。交给 B1-03 和 B1-05 一份可用示例。
2. AGY CLI 和桌面分别发现和读取。Codex CLI 与桌面按实际数据格式验证，共享同一份记录时保持一致的去重身份。独立账户同名记录保持各自身份。复用已支持的解析、读取上限和缓存行为，跟随实例启停。来源数据只读，验收采用授权的脱敏样本或合成夹具。
3. 扫描失败、损坏样本、取消和实例停用都只影响相应来源。停用停止接收新任务，并取消可取消的在途读取。实现一个用公开 SDK 和同一服务契约安装的第三方样例，与预装来源同时运行。
4. 本任务拥有来源发现和格式解析。B1-03 负责导入事务，B1-05 负责界面，B1-06 负责发行配置。对 SDK 或兼容入口有需求时，记录调用场景和用例交对应所有者。

## 自测与交付

- 用 Codex CLI、Codex 桌面、Claude CLI、AGY CLI、AGY 桌面五行记录样本来源、产品或格式版本、发现结果、正文读取结果和失败原因。扫描到标题但正文缺失时分开记录。样本不足的场景写明查过的索引或目录，标为待验证。
- 测试两个实例同时工作、加载顺序变化、单来源失败、分页续读、停用与恢复。对比真实脱敏数据、回放和合成夹具的覆盖范围。运行适用的 daemon 测试和类型检查。
- 交付基线、任务提交或 PR、插件入口与配置示例、第三方样例安装步骤、五类来源矩阵、实跑命令和结果。把可复用的脱敏夹具及复现步骤交 B1-06，由总指挥独立复验。
