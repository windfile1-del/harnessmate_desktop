## 实现与所有权

| 内容 | 所有者 / 入口 |
| --- | --- |
| ChatStage、内嵌 Composer、Markdown/工具/消息投影、会话命令与业务 store | `packages/web/src/plugins/chat-default/`，插件自己的 Vite 前端产物 |
| 聊天草稿、附件引用、终端上下文、视图 traits 与滚动位置 | `hm.plugin.chat-default` 的实例 KV：`view:<sessionId>`，带 revision/sourceId |
| 会话、事件、运行记录、提交边界与恢复 | W1 的 `session.data.v1` / `session.runtime.v1`；未复制数据库所有权 |
| 驱动命令/配置与协作 | W2 的公开服务与原兼容 HTTP 路由；未自行重写 W1/W2 |
| App 挂载与选择 | 解析 `chat.view.v1` 的 workspace/session 绑定，统一 `BoundSessionSurface`；缺实例显示不可用，无宿主 ChatStage fallback |
| 通用服务调用、批订阅、撤销和代次 | daemon `routes/ui-services.ts`、共享 WS、sandbox bridge；默认/外部相同 |
| Sidebar、Inspector、设置、插件中心、远程及 AGY native 管理 | 现有宿主，第四/五批范围；通过显式 DTO/允许的 shell action 保留行为 |

默认插件 `plugins/bundled/hm.plugin.chat-default` 提供 `chat.view.v1` 与 `workspace.pages/chat`，在预装组合中普通绑定；外部样例在 `plugins/examples/hm.plugin.chat-lite`。默认前端构建守卫拒绝把宿主 `stores/app-store.ts` 的运行时代码打入插件。类型引用不带入宿主 Zustand 对象；插件复用宿主一条 `DaemonWsClient`，不另起全局连接。

旧 `components/ChatStage.tsx`、`lib/projector.ts` 和 `lib/work-groups.ts` 是兼容导出，不是宿主挂载或 fallback。宿主保留供未迁领域使用的兼容类型/空字段，停止 active chat 的历史抓取与 canonical event 投影；草稿兼容动作转调所选 `chat.view.v1`。

调用携带 caller instance/runId 和目标 scope，拒绝停用/旧代次、保留服务和内部驱动适配方法。订阅先注册监听，再确认快照边界，按 16ms 或 256 项批量转发；WS 堵塞超过 2MiB 时 reset 并释放。连接、实例生命周期与显式取消均清理监听/定时器。客户端初始队列最多 512 批，溢出重新从已提交事件同步。以 provider/stream/run/session/seq 去重、补间隙和拒绝迟到结果；历史分页固定 throughSeq，投影增量处理新增事件。

页面桥同时提供显式 shell DTO、文件导航、剪贴板、导出下载、附件图片、终端输出及通用本地 `/api/v1/` transport。后者沿用本地 UI 的 API 访问边界，不是按聊天功能逐项加权限；禁止路径逃逸和宿主内部适配操作。这个通用 HTTP 入口的权限收窄属于后续整体插件安全边界工作，不能把它描述为细粒度的页面能力隔离。

为容纳原 React/Markdown/语法高亮前端（JS 约 1.583MB、CSS 约 21.37KB），页面资源通用上限调整为 2MiB asset / 4MiB HTML。性能预算未调整。历史不在每批跨桥重发；本地不可变数组追加仍复制事件引用，投影器按增量边界消费，后续可继续优化其内存分配。
